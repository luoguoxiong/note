## 跨越速运智能客服 Agent 系统

**项目角色：** 独立设计与开发

**技术栈：** Node.js、LangGraph、LangChain、DeepSeek、Express、SSE、PostgreSQL、Redis、Zod

**项目背景：** 面向物流场景中的运单查询、运费时效、网点查询及寄递政策咨询，设计并开发智能客服 Agent，打通自主工具调用、缺参中断与断点恢复、跨会话长期记忆及人工客服协同，并完成多实例部署与故障恢复验证。

**核心工作：**

1. **Agent 编排与工具调用：** 基于 LangGraph `StateGraph`、`ToolNode` 构建 ReAct 执行图，通过 `bindTools` 接入运单、运费时效、知识库、网点 4 类业务工具；支持自主工具选择、多轮调用、并行工具执行及上下文继承，结合 `recursionLimit` 控制执行轮次，并通过 `updates` / `messages` 双流将工具调用与 Token 增量转换为结构化 SSE 事件。

2. **Human-in-the-loop 与断点恢复：** 针对工具参数缺失场景，通过 `interrupt()` 挂起工作流，使用 PostgreSQL `PostgresSaver` 持久化检查点，前端补参后通过 `Command({ resume })` 恢复执行；结合 Redis TTL、`GETDEL` 原子消费、待恢复任务注册表及过期清理机制，实现跨实例续跑与重复提交防护。

3. **跨会话长期记忆：** 设计用户画像与会话摘要双层记忆，支持异步提取、置信度合并、冲突消解、时间衰减、版本追溯及 TTL 淘汰；按相关性与时效性排序召回 Top 8 记忆并注入上下文，用于历史偏好识别和工具参数预填，同时支持用户主动遗忘及敏感信息过滤。

4. **持久化与异步任务可靠性：** 使用 PostgreSQL 统一管理对话历史、人工会话状态、长期记忆及 LangGraph 检查点；通过事务、`pg_advisory_xact_lock` 用户级锁和唯一索引控制并发写入与数据一致性。异步记忆任务采用 `FOR UPDATE SKIP LOCKED` 认领，结合去抖合并、指数退避及租约回收，降低多实例重复消费和进程异常退出导致的任务丢失风险。

5. **多实例扩展与客服协同：** 将工作流挂起槽位、限流窗口、客服在线状态及 SSE 跨实例事件分发接入 Redis；采用本地 SSE 直写与 Redis Pub/Sub 桥接，实现跨实例事件推送；通过条件更新（CAS）控制人工接入竞争，结合心跳、短 TTL 缓存及入口限流，提升多实例下的协同与运行可靠性。

6. **可观测与自动化评测：** 建立一键执行的六阶段评测流程（`npm run eval`），覆盖工具选择与参数组装、缺参补全、记忆写入与召回、并发压测及故障恢复；将 Agent 决策、工具调用、记忆命中和工作流挂起等过程转换为结构化事件，支持问题定位、缺陷修复与回归验证。

**项目成果：**

- **Agent 功能验证：** 24 条话术 × 6 类意图回归评测中，工具选择与参数组装准确率达 **100%**；缺参补全成功率达 **100%**，覆盖规则快速处理与图内中断恢复共 4 类场景。
- **长期记忆验证：** 完成记忆写入、跨会话召回及纠正更新的端到端验证；3 组用户画像、15 条事实探测中，记忆召回 `Recall@8` 达 **100%**。
- **性能与故障恢复：** 10 并发、50 次请求压测成功率达 **100%**，首 Token 延迟 P50 为 **2.14 秒**、P95 为 **2.53 秒**，吞吐约 **185 req/min**；5 轮 `SIGTERM` 重启故障注入中，对话历史、人工会话状态及挂起任务恢复成功率达 **100%**。
- **多实例验证：** 双实例实测通过跨实例工作流续跑、Redis Pub/Sub SSE 事件转发及实例重启恢复场景，验证挂起任务与人工会话状态可跨实例恢复。
