# CellGroup

## 基本使用

```html
<template>
  <ky-cell-group></ky-cell-group>
</template>
```

## 组件API

### Attributes
| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| ---- | ---- | ---- | ---- | ---- |
| border | 是否显示边框 | boolean | - | true |
| title | 分组标题 | string | - | - |
| inset | 是否设置为内嵌样式 | boolean | - | false |

### Slots
| 名称 | 说明 |
| ---- | ---- |
| default | 单元格内容 |
| title | 自定义标题内容 |
