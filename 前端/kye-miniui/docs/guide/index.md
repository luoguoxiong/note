# 组件库介绍
kye-miniui Vue组件库, 基于 Taro，使用 Vue 技术栈开发小程序应用，开箱即用，帮助研发快速开发用户界面，提升开发效率，改善开发体验。

## 特性

* 🚀 40+ 高质量组件，覆盖移动端主流场景
* 💪 支持一套代码同时开发 H5+多端小程序+多端app
* 🍭 支持按需引用
* 📖 详尽的文档和示例
* 💪 支持 TypeScript
* 🍭 支持组件级别定制主题
* 💪 支持区别于其他组件库的丰富的交互体验
* 💪 支持区别于其他组件库多端代码强大的适配
* 💪 支持Taro4 + Vue3最新的特性支持
