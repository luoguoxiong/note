## ADDED Requirements

### Requirement: 服务方式查询

用户填写寄收地址等表单信息后，点击"查询"按钮，系统 SHALL 调用 `getQueryServiceTime` API 获取可用服务方式列表并展示。

#### Scenario: 查询成功
- **WHEN** 用户点击"查询"按钮，且寄收地址均已填写
- **THEN** 系统调用 API，loading 态展示，返回结果显示在 service-mode 组件中

#### Scenario: 地址校验不通过
- **WHEN** 用户点击"查询"按钮，但寄件地址或收件地址为空
- **THEN** 系统 Toast 提示"请填写寄件地址"或"请填写收件地址"，不发起请求

#### Scenario: API 返回空结果
- **WHEN** API 返回的 `serviceModeResponse.serviceTypes` 为空数组
- **THEN** 系统展示空状态文字"该地区未查到相关时效信息"

---

### Requirement: 重置功能

系统 SHALL 提供"重置"按钮，一键清空所有表单输入和查询结果。

#### Scenario: 点击重置
- **WHEN** 用户点击"重置"按钮
- **THEN** 系统清空所有表单字段（寄收地址、货好时间、重量、体积、托寄物、包装服务）及查询结果

---

### Requirement: 服务方式列表展示

系统 SHALL 以列表形式展示每条服务方式的名称、时效描述和预估费用。

#### Scenario: 列表项展示
- **WHEN** 查询返回多条服务方式
- **THEN** 每条展示：服务方式名称（`serviceTypeName`）、时效描述（`descriptionH5Text`）、预估费用信息

#### Scenario: 不可用项置灰
- **WHEN** 某条服务方式的 `restrictFlag` 为 `'10'`
- **THEN** 该条展示为灰色背景，右上角显示禁用标签和原因，不展示费用

#### Scenario: 延迟提示
- **WHEN** 某条服务方式的 `delayTips` 有值且 `usableFlag` 不为 `'20'`
- **THEN** 该条下方展示橙色延迟提示文字

---

### Requirement: 预估费用展示

有费用权限时，系统 SHALL 展示总费用（格式 `¥ xx.xx 起`，保留2位小数）和【明细】入口。无费用权限时展示 `¥***`。

#### Scenario: 有费用权限
- **WHEN** 用户已绑码且已开通费用查看权限
- **THEN** 每条服务方式展示总费用 `¥ xx.xx 起` + 【明细】链接，总费用 = 基础运费 + 增值费

#### Scenario: 无费用权限
- **WHEN** 用户已绑码但未开通费用查看权限
- **THEN** 每条服务方式展示 `¥***`，"预估费用"排序按钮隐藏

#### Scenario: 未绑码
- **WHEN** 用户未绑定客户编码
- **THEN** 展示空状态，"预估费用"排序标题隐藏

---

### Requirement: 排序互斥

系统 SHALL 支持按"预计时效"或"预估费用"排序，两种排序互斥。

#### Scenario: 默认排序
- **WHEN** 首次加载查询结果
- **THEN** 列表按 API 返回顺序展示，两个排序按钮均为无排序状态

#### Scenario: 点击预计时效排序
- **WHEN** 用户首次点击"预计时效"排序
- **THEN** 按预计到达时间降序排列，"预计时效"按钮展示降序图标，"预估费用"恢复无排序状态

#### Scenario: 再次点击预计时效排序
- **WHEN** 用户再次点击"预计时效"排序
- **THEN** 按预计到达时间升序排列，"预计时效"按钮展示升序图标

#### Scenario: 点击预估费用排序
- **WHEN** 用户首次点击"预估费用"排序
- **THEN** 按预估费用降序排列（NaN 和置灰项排最后），"预估费用"按钮展示降序图标，"预计时效"恢复无排序状态

#### Scenario: 再次点击预估费用排序
- **WHEN** 用户再次点击"预估费用"排序
- **THEN** 按预估费用升序排列，"预估费用"按钮展示升序图标

---

### Requirement: 表头展示

系统 SHALL 在列表顶部展示表头，包含"服务方式"、"预计时效"排序按钮、"预估费用"排序按钮（条件显示）。

#### Scenario: 有费用权限时表头
- **WHEN** 用户已绑码且有费用权限
- **THEN** 表头展示"服务方式" + "预计时效"排序按钮 + "预估费用"排序按钮

#### Scenario: 无费用权限时表头
- **WHEN** 用户未绑码或无费用权限
- **THEN** 表头仅展示"服务方式" + "预计时效"排序按钮，不展示"预估费用"

---

### Requirement: 底部提示

系统 SHALL 在服务方式列表底部展示提示文案。

#### Scenario: 列表底部提示
- **WHEN** 服务方式列表渲染完成
- **THEN** 列表底部展示"查询的预估运费不包含货物实际产生的增值费用，预估运费仅供参考"

---
