## Why

为 goods-time-popup 组件创建使用文档，帮助团队成员快速理解组件的功能、接口和使用方式，提高开发效率和代码可维护性。当前组件缺乏完整的文档说明，新开发者难以快速上手。

## What Changes

- 创建组件使用文档 `src/modules/order-global-package/components/ui/goods-time-popup/index.md`
- 文档包含：组件介绍、结构说明、Props 属性、Events 事件、类型定义、使用示例、核心逻辑说明和注意事项

## Capabilities

### New Capabilities
- `goods-time-popup-doc`: 货好时间选择弹窗组件的完整使用文档，包含 API 说明、类型定义和使用示例

### Modified Capabilities
- 无

## Impact

- 新增文件：`src/modules/order-global-package/components/ui/goods-time-popup/index.md`
- 不影响现有业务逻辑和功能实现
- 不涉及 API 变更或破坏性改动
