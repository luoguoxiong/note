## Context

goods-time-popup 组件是订单模块中用于选择货好时间的底部弹窗组件，支持线上模式（按时间批次选择）和自定义模式（自由选择时间）。当前组件缺乏完整的使用文档，导致新开发者难以快速理解和使用该组件。

## Goals / Non-Goals

**Goals:**
- 创建完整的组件使用文档，包含 API 说明、类型定义、使用示例
- 文档结构清晰，便于开发者快速查找所需信息
- 文档与代码保持一致，准确反映组件的功能和接口

**Non-Goals:**
- 不修改组件的业务逻辑或实现
- 不添加新功能或修改现有 API
- 不涉及性能优化或重构

## Decisions

1. **文档格式**: 使用 Markdown 格式编写，便于阅读和版本控制
2. **文档位置**: 放置在组件目录下（`src/modules/order-global-package/components/ui/goods-time-popup/index.md`），与组件代码保持邻近，方便查阅
3. **文档结构**: 遵循标准组件文档结构：组件介绍、Props、Events、类型定义、使用示例、核心逻辑说明、注意事项
4. **类型定义**: 从 `goods-time.ts` 文件中提取并整理，确保文档与代码一致

## Risks / Trade-offs

| Risk | Mitigation |
|------|------------|
| 文档与代码不同步 | 文档中引用类型定义时保持简洁，重点说明使用方式而非实现细节 |
| 文档过于冗长 | 保持文档简洁，重点突出关键信息，使用表格和代码块提高可读性 |
| 版本兼容性 | 文档中不标注版本号，保持通用性 |
