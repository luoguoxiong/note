# order-page-copy Specification

## Purpose

定义单票寄件下单页提示文案的口径契约，当前覆盖移动端收方手机/固话二选一提交校验报错文案；接口下发文案（实名认证引导、区域限行）与 PC 端静默文案不在本能力范围。

## ADDED Requirements

### Requirement: 收方手机固话二选一提交报错文案

单票寄件提交运单时，若收方手机号与固定电话均未填写，系统 MUST 拦截提交并在校验字段下方展示报错提示，提示文案 MUST 为「手机或固话至少填写一项」。该要求 MUST 在微信小程序（weapp）、支付宝小程序（alipay）、H5 三端表现一致。

#### Scenario: 收方手机与固话均为空时提交被拦截

- **WHEN** 用户在单票寄件页未填写收方手机号与固定电话，点击提交运单（weapp / alipay / H5）
- **THEN** 提交被拦截，校验字段下方展示报错文案「手机或固话至少填写一项」

#### Scenario: 收方填写任一项后可正常提交

- **WHEN** 用户填写收方手机号或固定电话中的任意一项后点击提交运单
- **THEN** 二选一校验通过，不展示报错文案，提交流程与线上逻辑一致

#### Scenario: 校验触发条件保持不变

- **WHEN** 收方手机号为必填（由配置控制）或已填写固定电话
- **THEN** 不触发二选一报错文案，校验行为与线上逻辑一致
