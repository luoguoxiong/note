# Spec Delta: waybill-card-fields

## ADDED Requirements

### Requirement: 付款方式字段组件
系统 SHALL 提供付款方式字段组件，当卡片配置中 `payMode` 字段开启时在运单卡片展示付款方式，展示格式为“付款方式：<值>”，值域为寄方付、收方付、第三方付（独立展示，不与结算方式组合）。

#### Scenario: 字段开启且有值
- **WHEN** 用户在列表个性设置中开启付款方式，且运单数据中付款方式有值
- **THEN** 运单卡片展示“付款方式：寄方付”（或收方付/第三方付）

#### Scenario: 字段开启但无值
- **WHEN** 用户已开启付款方式，但运单数据中无付款方式值或值为空
- **THEN** 隐藏“付款方式”标题和值，不渲染该行（不展示“付款方式：--”）

#### Scenario: 加密运单
- **WHEN** 客户后台电子存根对付款方式设置了半加密/全加密，后端返回加密值
- **THEN** 直接展示后端下发的加密内容，如“付款方式：***”

#### Scenario: 字段未开启
- **WHEN** 用户未开启付款方式或运单状态对应配置中无该字段
- **THEN** 运单卡片不渲染付款方式行

#### Scenario: 兜底配置降级
- **WHEN** 卡片配置接口失败走本地默认配置兜底
- **THEN** 运单卡片不展示付款方式行（默认配置不包含该字段，符合默认关闭）
