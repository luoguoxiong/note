# 路由规范

## 路由跳转

```typescript
import Taro from '@tarojs/taro'

// 普通跳转
Taro.navigateTo({ url: '/modules/waybill/pages/waybill-detail/index?id=123' })
// TabBar 切换
Taro.switchTab({ url: '/layout/pages/home/index' })
// 返回
Taro.navigateBack({ delta: 1 })
// 重定向
Taro.redirectTo({ url: '/pages/entry/index' })
```

## TabBar 路由

| Tab | 路径 | 文本 | 图标 |
|-----|------|------|------|
| 首页 | layout/pages/home/index | 首页 | menu_home |
| 寄件 | layout/pages/order/index | 寄件 | menu_order |
| 查件 | layout/pages/waybill/index | 查件 | menu_search |
| 我的 | layout/pages/mine/index | 我的 | menu_mine |

- 入口页: layout/pages/home/index
- TabBar 选中色: #8565F3
- TabBar 切换使用 Taro.switchTab

## 路由配置

- 主包页面: `src/mainpackages.ts`
- 微信子包路由: `src/wx.config.ts`
- 支付宝子包路由: `src/alipay.config.ts`
- 子应用构建: `src/subpackagesConfig.ts`
- **新增页面必须同时在 wx.config.ts 和 alipay.config.ts 注册**

## 导航 API

使用 Taro API 替代浏览器 API：
- Taro.navigateTo / Taro.switchTab / Taro.redirectTo / Taro.navigateBack
- **禁止使用 window.location / history.pushState 等浏览器 API**
