# 埋点规范

## 埋点类型

| 类型 | 命名模式 | 说明 |
|------|----------|------|
| PV | reportXxxUv | 页面访问量 |
| 点击 | reportXxxClick | 元素点击事件 |
| 曝光 | reportXxxExposure | 元素曝光事件 |
| 事件 | reportXxxEvent | 自定义事件 |

## 使用方式

```typescript
import { reportXxxUv, reportXxxClick } from './report'

// PV 上报
onMounted(() => {
  reportXxxUv()
})

// 点击上报
const handleClick = () => {
  reportXxxClick({ btnName: 'submit' })
}
```

## 基础设施

- 使用 `@public/utils/aplusConfig` 进行埋点上报
- 公共埋点工具位于 `@public/report/`
- 各模块的埋点放置在模块的 `report/` 目录下

## 模块埋点文件

各模块在 `report/` 目录下维护自己的埋点上报函数：

- `src/layout/report/` - 首页/我的/搜索埋点
- `src/modules/user/report/` - 用户模块埋点
- `src/packages/idcard/idcard-report/` - 智慧名片埋点
