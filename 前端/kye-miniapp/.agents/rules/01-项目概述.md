# 项目概述

## 项目简介

跨越速运小程序 (kye-miniapp) — 基于 Taro 4 的多端小程序项目，支持微信小程序、支付宝小程序和 H5 端。

## 技术栈

- **框架**: Taro 4 + Vue 3 (Composition API)
- **状态管理**: Pinia (defineStore 模式)
- **类型系统**: TypeScript
- **样式**: Sass (SCSS)
- **构建工具**: Vite
- **UI 组件库**: @kye-netc/kye-miniui (自研)

## 多端支持

| 平台 | TARO_ENV | 配置文件 | 渲染模式 |
|------|----------|----------|----------|
| 微信 | weapp | wx.config.ts | webview + glass-easel |
| 支付宝 | alipay | alipay.config.ts | skyline + glass-easel |
| H5 | h5 | wx.config.ts | 浏览器 |

## 路径别名

| 别名 | 路径 |
|------|------|
| @/* | ./src/* |
| @public/* | ./src/public/* |
| @modules/* | ./src/modules/* |
| @layout/* | ./src/layout/* |
| @order-public/* | ./src/modules/order-build/order-public/* |

## 开发命令

```bash
# 微信小程序
yarn dev:wx
yarn build:wx:prod

# 支付宝小程序
yarn dev:alipay

# H5
yarn dev:h5

# 代码检查
yarn eslint
```
