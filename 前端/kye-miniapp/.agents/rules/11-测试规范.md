# 测试规范

## 测试策略

本项目为小程序项目，测试策略以手动测试为主，辅以代码审查和类型检查。

## 代码质量检查

- 使用 ESLint 进行代码规范检查: `yarn eslint`
- TypeScript 编译检查: `yarn build` 时自动检查
- 遵循项目的代码规范和命名约定

## 开发自测流程

1. **编译检查**: 确保 TypeScript 编译无错误
2. **代码规范**: ESLint 检查通过
3. **功能测试**: 在对应平台（微信/支付宝/H5）进行功能验证
4. **回归检查**: 确保不影响现有功能

## 多端测试

| 平台 | 测试方式 |
|------|----------|
| 微信小程序 | 微信开发者工具 + 真机 |
| 支付宝小程序 | 支付宝小程序开发者工具 + 真机 |
| H5 | 浏览器 + 移动端浏览器 |

## 注意事项

- 新增页面后检查路由配置是否正确
- 修改接口后检查类型定义是否匹配
- 多端适配需要分别在微信和支付宝端验证
- 涉及原生能力需在真机上测试
