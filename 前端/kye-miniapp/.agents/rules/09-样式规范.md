# 样式规范

## 技术选型

- 使用 Sass（SCSS）编写样式
- 使用 scoped 样式隔离

## 单位规范

- **小程序**: 使用 rpx 单位（750 设计稿基准）
- **H5**: 使用 px 单位
- **禁止使用 rem/vw/vh** 等单位

## 样式文件规范

- 每个 Vue 组件同步创建同名 `.scss` 文件
- 样式写在单独的 scss 文件中，不写在 vue 文件内
- 使用 `<style lang="scss" scoped>` 包裹组件样式

## 命名规范

- 使用 BEM 或 kebab-case 命名
- 最多 3 层嵌套
- **禁止创建全局样式**，使用 scoped 样式

## CSS 规范

```scss
// BEM 命名示例
.block { ... }
.block__element { ... }
.block--modifier { ... }

// kebab-case 命名示例
.waybill-card { ... }
.waybill-card__title { ... }

// 最多 3 层嵌套
.waybill-card {
  &__header {
    .title { ... }
  }
}
```

## 禁止事项

- 不要使用 DOM 操作样式（本项目是小程序项目）
- 使用 Taro API 替代浏览器 API 操作样式
- 不要使用 Element Plus / Ant Design Vue 等 PC 端 UI 库的样式
