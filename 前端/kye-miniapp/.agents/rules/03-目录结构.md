# 目录结构

## 顶层目录

```
kye-miniapp/
├── src/                    # 源码目录
│   ├── layout/             # 主页面 (TabBar 4页面，路径别名 @layout/)
│   ├── modules/            # 业务子模块 (每个模块对应一个 subPackage)
│   ├── packages/           # 业务功能包 (独立功能集合)
│   ├── public/             # 公共基础设施层 (路径别名 @public/)
│   ├── pages/              # 中转/入口页
│   ├── store/              # 全局 Store
│   ├── subpackages/        # 测试子包
│   ├── subpackages-expand-customer/ # 客户扩展子包
│   ├── directive/          # 全局指令
│   └── types/              # 全局类型定义
├── config/                 # 构建配置
├── miniapp/                # 小程序原生配置
├── types/                  # 全局类型声明
└── .agent/                 # AI 助手配置 (旧)
```

## 模块目录规范

```
module-name/
├── index.vue              # 入口页面
├── index.scss             # 页面样式
├── index.config.ts        # Taro 页面配置
├── apis/                  # 接口 (index.ts + types.ts)
│   ├── index.ts
│   └── types.ts
├── hooks/                 # 组合式函数
├── store/                 # 页面级 Store
├── components/            # 子组件
├── config/                # 配置
├── utils/                 # 工具函数
└── report/                # 埋点上报
```

## 公共层 public/ 目录

```
public/
├── apis/                  # API 接口 (11子模块)
├── appInit/               # 应用初始化 (5阶段)
├── appPlugins/            # App端原生插件
├── appxenv/               # 灰度泳道环境
├── components/            # 公共组件
├── config/                # 多端环境配置
├── constants/             # 常量定义
├── hooks/                 # 通用 Composable (28+)
├── utils/                 # 工具函数集 (20+子模块)
├── storage/               # 持久化存储
├── router/                # 路由重定向
├── socket/                # WebSocket 通信
├── report/                # 埋点上报
├── plateform/             # 飞书平台适配
├── lib/                   # 第三方 SDK
├── native/                # 原生文件上传通信
└── h5/                    # H5端适配
```
