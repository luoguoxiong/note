# 技术栈

## 核心框架

- **Taro 4**: 多端统一开发框架，一套代码编译到微信小程序、支付宝小程序、H5
- **Vue 3**: Composition API + `<script setup lang="ts">` 模式
- **TypeScript**: 严格模式，target ES2017
- **Pinia**: 状态管理，defineStore 模式

## UI 组件库

- **@kye-netc/kye-miniui**: 自研小程序 UI 组件库
- **禁止使用** Element Plus / Ant Design Vue 等 PC 端 UI 库
- **禁止使用原生表单元素**（input/textarea/button），必须使用 ky-field/ky-upload/ky-button

## HTTP 请求

- **统一使用 http()** from `@public/utils/request`
- 基于 Axios，自动携带 token/sign/灰度头
- **禁止直接使用 axios**

## 构建与代码检查

- **Vite**: 构建工具
- **ESLint**: `taro/vue3 + eslint:recommended + plugin:prettier/recommended`
- **Prettier**: `semi: false, singleQuote: true, printWidth: 120`
