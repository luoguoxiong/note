## 基础代码规范

### 函数规范

| 规则 | 说明 |
|------|------|
| 单一职责 | 每个函数只做一件事，函数名应能准确描述其行为 |
| 函数长度 | 单个函数不超过 **50 行**（不含注释和空行） |
| 参数数量 | 函数参数不超过 **3 个**，超出时使用对象参数 |
| 禁止嵌套逻辑 | 条件/循环嵌套不超过 **2 层**，深层逻辑需提取为独立函数 |
| 提前返回 | 使用 Guard Clause（提前返回）减少嵌套，避免 else |

### 组件规范

| 规则 | 说明 |
|------|------|
| 组件长度 | 单个 `.vue` 文件不超过 **300 行** |
| Composable 拆分 | 复杂逻辑抽取到 `useXxx` composable，组件只负责视图绑定 |
| Props 类型 | 所有 props 必须声明 TypeScript 类型，禁止使用 `any` |

### 通用规范

| 规则 | 说明 |
|------|------|
| 禁止魔法数字 | 数字/字符串常量必须提取为具名常量 |
| 禁止注释代码 | 废弃代码直接删除，不允许注释保留 |
| 变量声明 | 优先使用 `const`，需要重新赋值时使用 `let`，禁止 `var` |
| 异步处理 | 统一使用 `async/await`，禁止 `.then()` 链式调用混用 |
